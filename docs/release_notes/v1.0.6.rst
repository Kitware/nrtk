v1.0.6
======

.. admonition:: JATIC Maturity I
   :class: note

and sets the minimum NRTK version to 1.0.5 in notebooks included in CI.

Fixes
-----

* Fixed production regression CI checkout failures on Kubernetes runners by trusting the job's checkout directory.

* Required NRTK 1.0.5 or newer in the setup cells of notebooks included in CI.
